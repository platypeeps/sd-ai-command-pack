Look only at the interrogation question the response asks (ignore the
classification and its override invitation).

Pass if the question asks the user for one thing. Detail that says what a good
answer to that one thing contains, such as an example and its particulars, is
part of it. Fail if the question also asks for a second, separate thing to
answer, such as a frequency, a count, a second decision or an unrelated fact.
Name the second thing when it fails.
