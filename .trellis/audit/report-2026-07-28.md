# Repo Audit — sd-ai-command-pack @ 49b43afd — 2026-07-28

Mode: full · Depth: standard · Dimensions: architecture, bloat, correctness,
consumer-impact, dependencies, design, documentation, improvements,
performance, release-hygiene, security, testing, tooling
checkout-trust: trusted (trusted_local_branch)

## Verdict

The pack works, ships, and gates itself heavily — but the guard machinery has
outgrown the thing it guards. Thirteen read-only reviewers returned 90 raw
findings; synthesis merged seven cross-dimension duplicates into 83. The single
worst result is not complexity but a branch-protection bypass: the CI fast lane
decides whether the expensive lanes run by executing a classifier read out of an
attacker-controllable commit, and the only required merge context reports green
when they are skipped. Beneath that, the dominant pattern is duplication policed
by machinery instead of removed: 2.0 MB of committed generated mirrors guarded
by ~210 KB of drift checkers, state-root helpers written three times, the cache
contract restated four times, the receipt schema declared twice in two
languages, and four review surfaces alive at once with no removal version. The
tracking layer the user flagged is real: the payload digest gate forces an
eight-consumer revalidation for a typo, and the `environment_blocked` schema —
five typed fields, enums, a redactor and a round-trip validator — has no
machine consumer at all.

Counts by severity: P0 1 · P1 5 · P2 42 · P3 35 (total 83).
Confidence: Verified 7 · Plausible 76.
