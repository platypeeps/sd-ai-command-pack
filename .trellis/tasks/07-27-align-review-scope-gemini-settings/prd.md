# Align review-scope classifier for Gemini settings

## Goal

Keep the shell review-scope copied-path classifier aligned with preflight for .gemini/settings.json.

## Requirements

- Add `.gemini/settings.json` to the shell review-scope classifier's Trellis/runtime copied-path set.
- Keep the root script and shipped template byte-aligned.
- Add focused parity coverage so the shell and JavaScript classifiers cannot silently diverge for platform settings paths.

## Acceptance Criteria

- [x] `.gemini/settings.json` is classified as copied/generated by both
  review-scope implementations. Already true — shell `is_trellis_runtime_path`
  (`.gemini/settings.json` in the settings group) and the mjs
  `isTrellisCopiedPath` (`path === '.gemini/settings.json'`) both classify it;
  no classifier change was needed, only the guard coverage below.
- [x] Focused classifier tests and `make check` pass. Added a
  `copiedTemplateKind('.gemini/settings.json')` assertion in
  tests/test_review_preflight.py and behavioral shell test
  `test_gemini_settings_are_scoped_as_copied` in tests/test_review_scope.py;
  both green and `make check` passes.
- [x] The next release payload and consumer audit remain valid. This change
  touches only `tests/**` (not a shipped/installed target), so the release
  manifest, provenance, and candidate ledger are byte-unchanged (`make generate`
  closure clean, 0 written).
